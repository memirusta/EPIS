# EPIS Personality Seed — Public Template

The private project uses a user-specific communication seed derived from observed interaction patterns. That personal profile is deliberately **not** published.

A deployment can build its own seed from explicit user feedback and non-sensitive conversational preferences, for example:
- preferred answer length
- technical depth
- language-switching preferences
- tolerance for humor
- preferred correction style

The seed should influence *how* EPIS communicates, not dictate *what* the user believes.
